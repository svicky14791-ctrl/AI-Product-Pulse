# AI Product Pulse
## Overview
This project analyzes customer reviews and automatically generates:
- Theme Analysis
- Weekly Product Pulse
- Fee Explainer
- Human Approval Gate
- Gmail Communication
## Workflow
1. Upload Reviews CSV
2. Extract Reviews
3. Review Analysis
4. Weekly Product Pulse Generation
5. Fee Explainer Generation
6. Review Page
7. MCP Approval Gate
8. Email Generation
## Tech Stack
- n8n
- Anthropic AI / Gemini
- Gmail
## Outputs
- Weekly Product Pulse
- Fee Explainer
- Stakeholder Email
## Main Workflow
Upload Reviews → Extract Reviews → Review Analysis → Weekly Product Pulse → Fee Explainer → Review Page → Approval Gate → Gmail
