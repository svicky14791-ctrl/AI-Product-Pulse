# AI Product Pulse
## Overview
This project analyzes customer reviews and automatically generates:
- Theme Analysis
- Weekly Product Pulse
- Fee Explainer
- Human Approval Gate
- Google Sheets Update
- Gmail Communication
## Workflow
1. Upload Reviews CSV
2. Extract Reviews
3. Review Analysis
4. Weekly Product Pulse Generation
5. Fee Explainer Generation
6. Review Page
7. MCP Approval Gate
8. Google Sheets Update
9. Email Generation
## Tech Stack
- n8n
- Anthropic AI / Gemini
- Google Sheets
- Gmail
## Outputs
- Weekly Product Pulse
- Fee Explainer
- Google Sheet Entry
- Stakeholder Email
## Main Workflow
Upload Reviews → Extract Reviews → Review Analysis → Weekly Product Pulse → Fee Explainer → Review Page → Approval Gate → Google Sheets → Gmail
